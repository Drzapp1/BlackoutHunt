# Blackout Hunt 0.9.0 — the big one: secrets, awards, and a menu that boots into a nightmare

The last few releases were about getting live play to hold up — the modes starting, a full class surviving a round, the question nodes behaving. This one is a different kind of release. It's by far the biggest since the live-play work, and instead of hardening one slice it goes wide: a five-pass deep bug-hunt that makes rounds fairer and steadier, a whole achievements-cosmetics-prestige progression layer with a new Awards tab, lasting per-topic physics mastery, momentum movement tech you can chain, a top-to-bottom tutorial rebuild, a hidden HUB full of secrets you reach by pressing Escape at the menu, an atmospheric-horror menu reskin that opens with a fake cold-boot crash, per-part avatar recolouring with switchable UI themes, and playable train-lobby minigames you can actually sit down and play. There's a lot here, and a lot of it is brand new — so the beta caveat at the bottom matters more than usual. Here's what's in it.

## A five-pass deep bug-hunt

The foundation of this release is a multi-pass sweep through the whole codebase for correctness, stability, and security holes. The headline outcomes:

**Rounds end with the right winner.** The class no longer loses a round it already won. If the last survivor inside disconnects, gets infected, or gets captured *after* a classmate already escaped, the survivors are correctly credited the win instead of the Teacher. And if a classroom Wi-Fi blip drops the last survivors all at once, the game now waits out the full 120-second reconnect grace before handing the Teacher a win, instead of ending the round about a second later. A player who reconnects during the brief pre-travel window no longer gets dropped back into an already-decided round as a capturable survivor — they're marked out of play and shown the result card they missed.

**Single-breaker maps are winnable.** On smaller or custom maps that only have one power breaker, the exit door can now actually unlock so survivors can escape — before, the exit could never open and the round was simply unwinnable. The shipped 7–8 breaker maps are unaffected. Alongside this, a few edge cases that could leave a round frozen with no resolution now always resolve, so matches don't silently hang.

**The world looks right when you join late, and when you don't.** Join a match in progress and a door a survivor already opened now appears correctly — before, late-joiners could see that door spun roughly 180 degrees the wrong way, or a sliding gate lifted to double its real height. Decorative mesh props placed in a level now render their intended mesh on the host instead of a placeholder cube. And if you wander out of the carriage during the final ride, the game now boards you back in instead of stranding you alone in the tunnel.

**Bots and tutorials behave.** When a bot teammate gets captured or benched mid-objective, the rest of the bot team no longer treats that breaker as "taken" and avoids it for the next thirteen seconds — they keep working the objectives, so playing with AI feels more competent. Bots also stop briefly "forgetting" a hunter they personally just spotted, so their fleeing and hiding read more reliably. And the Counterplay tutorial's lesson finally tells the truth: when a student hides in a locker the on-screen STUDENT marker now disappears, instead of staying pinned to the locker and contradicting the whole point of the lesson.

**Fairer answering, cleaner HUD, honoured config.** Team-vote questions with more than four answer choices can now actually be voted through (they used to soft-lock and could never finish). The Teacher and Hall Monitor now see a compact BATTERY + STAMINA readout instead of three survivor-only meters sitting dead at zero. A player in the Tester role who swings the axe now sees the full swing animation, trail, and hit flash like the Teacher does. And if a host configures the flashlight to die completely during a blackout, it now truly goes dark — the default beam keeps its usual faint flicker.

**Teacher data is hardened.** Two security passes that players never see but that keep teachers safe: student-typed feedback can no longer turn into a malicious formula in the owner's Google Sheet (you'll need to redeploy the Apps Script to pick this up), the optional self-hosted account server is locked down against token replay, config tampering, and rate-limit spoofing, and a tampered client can no longer flood the lobby by spamming ready/unready. Custom teacher-authored question banks are now sanitized exactly like the built-in ones, so a malformed `QuestionBank.json` can't crash or pick an out-of-range "correct" answer.

There's a long tail underneath all of that — bounded memory so a host can run many back-to-back rounds without the game slowly bloating, correct level-of-detail settings so weaker classroom PCs actually get the cheaper detail levels, steadier per-player horror cues, and dozens of small defensive fixes that make hard-to-hit crashes less likely.

## A new Awards tab, and a reason to keep playing

This is the headline new system: Blackout Hunt now has progression. There's a brand-new **Awards** tab in the main menu, sitting next to Character, where you can browse every achievement as a badge. Each one shows a five-pip difficulty meter colour-coded by tier — Bronze, Silver, Gold, Platinum, Mythic — the title, what you did to earn it, the cosmetic it unlocks, and whether it's EARNED or still locked. Secret achievements show as "???" until you discover them, so there's a real sense of hunting. Badges sort as a difficulty ramp with earned ones bubbling to the top of each tier, and a header tells you "Earned N of M" at a glance.

The core loop is earn-to-unlock. Clearing an achievement awards XP and can unlock a hidden avatar **tint** — these show as mystery swatches in your colour picker and only become selectable once you've earned the matching achievement, then they stick. Your tint shows on your nameplate, the lobby roster, and map blips, so other players can see your rare colours. There are ten hidden tints in all (Chalk, Arcade, Exit Sign, Afterimage, Veteran, Faculty, Slipstream, Detention, Apex, Commuter). It's strictly cosmetic and never touches scoring, win/loss, mastery, or reports.

The best outfits are now rewards for *doing* things rather than just piling up XP. The Suit comes from winning a Hunt as a survivor, the Spacesuit from landing a Perfect Chain, the Farmer from playing 100 rounds, the Beach from ten escapes, the Punk from five wins in a row. Only the Adventurer stays as an early 100-XP carrot for brand-new players. Locked outfits sit visibly in the picker so you can see what you're working toward.

Two reward types show on your nameplate above *other* players, not just on your own avatar: **titles** (a line of text under your name — "Honors Student", "The Untouchable", "Speedrunner", "Graduate") and **emblems** (a small coloured badge beside your name — Chalk Star, Exit Sign, Crown, Halo, Ember). Unlike tints, these are replicated, so everyone in the lobby sees the flair you've earned. You pick your active title and emblem in the Character tab; survivors display flair, while Teachers and hall monitors stay anonymous by design.

The achievement list runs long and skews heavily toward secrets, so regulars always have a next thing to chase — progression awards like Centurion, Houdini, and Unstoppable, education awards like Valedictorian and Bookworm, and a wave of secrets like Pop Quiz (capture in the first 20 seconds), Ghost in the Walls (hide in a locker 25 times), Comeback Kid, Burning the Midnight Oil (play after midnight), and Don't Panic (play named 42 or Adams). Two capstones, Honor Graduate and Perfectionist, pop on their own the moment you complete the set. There's a second hidden menu code too: type **G 9 8 1** (gravity, 9.81 m/s²) on the main menu for the secret "It Still Pulls" achievement and the Falling Apple emblem.

Two more things make the tab feel alive. Countable achievements now show a tier-coloured fill bar and an "x / y" count on the badge, so you can see exactly how close you are (Veteran 18/25, Graduate 33/50). And when you earn something, the Awards button shows a count of unseen awards and the fresh badges light up with a "NEW!" marker until you've looked. At the top of the tab is a profile card: a school-themed rank derived from your total XP (Freshman all the way up to Valedictorian) with a progress bar, plus a lifetime stats card — rounds played, wins as Teacher and as Survivor, escapes, best win streak, and total awards earned.

One housekeeping note: hats are gone. The procedural achievement hats stacked awkwardly on the avatar models' built-in hats and looked wrong, so the entire Headwear category was removed. Every achievement that used to grant a hat now grants nameplate flair instead — Roof Rider gives a title, On a Roll a Crown emblem, Completionist a Halo and title — so you keep the reward, just in a form that looks right.

## Your physics answers build a lasting profile

Every physics question you answer in-round now feeds a lifetime mastery readout in the Awards tab. For each of the four topics — Forces & Motion, Electricity, Waves, Energy — you see a coloured fill bar plus your correct/total and a percentage, like "Forces & Motion  14/18  78%". It's cumulative and persists with your account, so you can watch a topic climb across many sessions instead of only seeing one round's recap. Topics you've never touched show a grey bar and "--". It's a personal, cosmetic readout — it doesn't change scoring, the in-round revision mechanics, or anything the teacher's class report shows.

The bars don't just display; they coach. A highlighted callout points you at your weakest topic ("Focus next: Waves (55%) — your weakest topic right now"). If every topic is at 80% or above it tells you you're exam-ready instead, and if you haven't answered enough yet it nudges you to practise more. A topic only counts once you've given it at least three answers, so one lucky or unlucky question can't throw the advice off.

And answering well earns recognition: get five right in a row for **Honor Roll**, or answer at least one correctly in each of the four topics across your account's lifetime for **Polymath**. Both reward a wearable nameplate title, and the streak resets to zero on a wrong answer, so Honor Roll genuinely means a clean run.

## Movement that flows

When a survivor rolled, slid, or dived, they used to brake to a dead stop the instant the move ended — the worst possible moment, right as they're trying to flee. Now the move's forward momentum carries through into a normal run, so escapes feel fluid and committed instead of stuttering to a halt, and chaining moves frame-perfectly visibly travels farther and faster. Momentum is deliberately *not* re-injected when you end prone, brake to a crouch, or bonk a wall — those are supposed to stop you — so the tech rewards skill without shoving you into the obstacle you just hit.

Those moves also animate properly in third person now. Previously another player watching you slide, dive, or go prone saw your body glide across the floor with its limbs frozen in whatever pose it last held — it looked broken. Each move now shows a sensible lunge, slide, and crawl. And the first-person roll camera settles smoothly when a roll is cut short: an interrupted barrel-roll used to snap upright in a single jarring frame, and now it eases back cleanly, with the full-style camera finishing the somersault forward so the flip never visibly reverses. If the forward camera tilt is too much motion for you, the first roll pops a one-shot card pointing you at the Roll Cam comfort setting — Off, Subtle, Dip, or Full.

One more thing, and it's the one that matters most in an actual game: this tech now works over the network, not just for the host. The frame-perfect flow chain and the hold-Shift-plus-Ctrl drop-roll used to fire only on the listen server — a connected student got nothing — because the timing window was measured purely in server time and the landing check ran a frame before the game registered the touchdown. The chain window is now latency-compensated so it's genuinely hittable on a real connection, the drop-roll fires reliably on the frame you land for every client, and rolling out of a locker no longer wedges your capsule into the wall behind it and soft-locks you in place. So the movement ceiling is the same whether you're hosting or joining.

## A complete tutorial and coaching overhaul

Every tutorial was rebuilt around how the game is actually played, not how it was first sketched out.

The **Movement** tutorial is no longer an empty room — it now spawns a small practice course in the western bay with a cover wall to roll under, a drop ledge with walkable stairs to drop-roll off, and a red DUMMY in a doorway to dive past, each with its own labelled marker. The coaching watches what you actually do and reacts: it counts your bunny-hop chain ("Nice — 2 in a row!"), tells you when you clipped a wall, and catches the classic mix-ups (you slid when you meant to roll, you pressed Alt on the ground instead of in the air for a dive). A practice locker sits right in the bay so the climb-out step doesn't drag you two rooms away.

The **Teacher** lesson now teaches in the order you actually hunt: you learn the READ tools — the Q scan to find a heartbeat, recognising decoy NOISE as a possible trick — *before* you're handed the COMMIT tool, the axe. The climax splits into two beats, Hunt (sprint to close the gap) and Capture (land the grab while you're right on top of them). The **Survivor** lesson got real stakes: a looming Teacher idling across the floor so everything you learn has a visible reason, a locker step that teaches the cabinet as a hiding spot in its own right — duck in with E, climb out, and you reappear a few steps away so a Teacher can't camp the door you went in — a decoy demo where you watch the Teacher get pulled toward where it landed, and a final encounter that waits until you've actually started moving for the exit instead of ending on a blind timer. The **Hall Monitor** lesson finally makes the tools *do* something — the Teacher looms idle as a baseline and reacts to each tool you fire, so a real hint sends it after the student, a false marker peels it off to an empty corridor, and a trap gets walked into and lights up a student's position.

Underneath that, a capture-immunity shield keeps the student you're watching (and you, in the Survivor lesson) from being grabbed early by a wandering Teacher, so a lesson can never end with a surprise capture — and it's cleared at round start so it can never leak into a live match. The scripted looming and practice Teachers are now genuinely parked in place so they menace instead of roaming. And the presentation got a pass: captions are larger, every wrapped line is centred, the 13 movement prompts were rewritten to short keys-first one-liners, latched-action steps keep their caption up for a two-second minimum so quick players can still read what they just did, and every tutorial now opens with a short two-note "login" chime. The in-menu Guide was reworked too, with a single canonical Movement Kit reference grid and in-fiction voice lines on each role card.

## The hidden HUB, and the secrets around it

There's a whole hidden layer in 0.9.0. From the main menu, when you're not in a live game, **pressing Escape now drops you into a secret back-room wing.** You spawn dead-centre in a dim, open gallery and free-roam with no lesson, no objective, and no scoring. Doorways lead off to a Movement Range, a Teacher Evasion room, and a secret room marked "?  ?  ?"; glowing plaques label everything, and a TROPHY HALL plaque prints your own lifetime record — rounds, survivor and hunter wins, escapes, best streak, mastery, achievements, and XP. A welcome card greets you ("YOU FOUND IT — The hidden HUB…"), and Escape again any time takes you back to the menu. The Teacher Evasion room has a Hunter bot standing in it that stays put and menaces in place, so it's a safe stationary sparring dummy to practise dodging around rather than something that hunts you while you read plaques.

There are smaller eggs scattered through normal play, all purely cosmetic and all gated behind a single toggle a teacher can flip off for a strictly plain session. Hide in a locker as a survivor and a faint line of carved physics-flavoured graffiti appears low on your screen — each locker keeps its own message, and only you see it while hidden. Name yourself after a famous physicist and you get a one-time personal welcome whisper the first time you spawn (Newton → "Somewhere, an apple falls in your honour."). When the building is calm, the shared mood line very rarely flickers to a hidden one ("something in the walls is solving for x.") — it only ever fires when nothing's wrong, so it never hides a real danger warning. And the main menu still hides the Konami code (Up Up Down Down Left Right Left Right B A) for a quiet thank-you line. The physicist list and the carving and whisper pools all grew this release, including a cheeky "42"/Adams greeting, so repeat players keep finding fresh lines.

The biggest egg rides the rails. During a subway intermission, if you go exploring in the front cab corner you'll find a small dark maintenance hatch tucked against the wall. Interact with it and you're lifted out onto the **roof of the train** — a low-railed walkway above the carriages with the tunnel rushing past, a quiet vantage to enjoy while the timer runs. The first trip up earns the Roof Rider achievement, and going up never blocks boarding because the intermission advances on its own timer. (You can always press O to drop back into the cabin.)

## A menu that boots into a nightmare

The first thing you see is no longer a flat, bright menu. On a cold first launch, Blackout Hunt now plays a one-time, skippable cinematic that pretends your machine is booting and then crashing: a full-screen flood of bare-metal boot text scrolling past, settling into a structured "facility" boot, then glitching into a giant red flickering **SYSTEM FAILURE** banner with a hard screen-shake, then stacking up fake Windows crash dialogs with increasingly unsettling messages ("BlackoutHunt.exe has stopped responding"… "It knows that you are here"… "he is already inside"), then dropping into a fake blue-screen that loads, suspiciously freezes, and quietly turns its sad-face angry. About half a second before the cut to black, something visibly intercepts it — the progress crawl snaps to 100%, the face flips to a knowing grin, and the whole screen tears like a broken digital signal before rebooting into the actual menu. It's got full sound design now — a low power-up hum, POST beeps, a static burst at the failure, a glitchy snap at the takeover — and it plays once per session, can be skipped, and is softened if you have reduced-flash on.

It lands on a new cinematic **"Dread"** menu, near-black and oppressive: the background crushed to a cold dim silhouette, a slow-breathing scrim, animated film grain, a danger-red accent that flickers like a failing light, and the title glowing ember-orange with an unsteady flicker. The old horizontal button row gives way to a vertical PLAY / HOW TO PLAY / CREDENTIALS / QUIT nav list with left accent bars that widen on hover, an in-fiction status line along the bottom ("SIGNAL: UNSECURED // POWER: FAILING") that reddens when the light dips, and a clean fade-in from black. The whole menu is fully keyboard-navigable now — arrows move a highlight that lights up exactly like a mouse hover, Enter or Space activates — which matters for accessibility and for anyone playing from the couch. Cards were lifted so panels stop blending into one flat black field, the in-menu screens carry the same grain and red breath for depth, and a real bug got fixed along the way: the new status line had been silently swallowing clicks on the credentials login panel, so the password field and Login button work again.

## Recolour every part, and pick your menu's colours

Picking a colour used to repaint your whole outfit a single flat tint, erasing the detail the artist gave each skin. Now every skin keeps its authored multi-colour look by default, and a new **Recolour Parts** picker in the Character tab lets you recolour each clothing piece on its own — just the hard hat, just the tie, just the spacesuit trim — with friendly labels and a small swatch on each part button so you can match it to the avatar. "Default" restores a part's original colour. Switching outfits rebuilds the part list for that skin's actual pieces, your recolours are saved and seen by other players, and the face, skin, hair, and eyes are protected so they never recolour by accident.

The avatar preview that shows all of this is bigger and no longer stretched — it renders at its correct 2:3 proportions with the camera pulled in closer so you can actually see your work. With the whole Headwear category removed this release (the procedural hats clashed with the models' built-in hats, and the face accessories went with them), the old "Shirt" colour is relabelled **Nameplate**, since with per-part recolour owning the skin, that colour now drives your nameplate identity. And there's a separate **UI Theme** picker with five presets — Classic, Midnight, Crimson, Emerald, and Arcade — for a personal menu look-and-feel that's instant to switch and changes nothing about gameplay.

## A train car you can actually play in

The between-rounds train is now a real lobby. Press **C** to sit down — your view eases to a seated height and your movement locks so you stay put, and the moment you press a movement key you stand right back up (other players see you genuinely seated, legs and all). And there are three real games to sit down at:

- **Blackjack.** Walk up to a table, take a seat, and play a real hand against a shared dealer. Several players can sit at once and each play their own hand at the same time — tap to deal or hit, hold to stand. Your cards, hand value, the dealer's up-card, your chips, and the prompt all show in a private panel on your own screen. Everyone starts with 500 chips and antes 25 a round; busting out triggers a free re-buy so nobody gets stuck broke, blackjack pays 3:2, and a 45-second turn timeout auto-resolves a hand if someone wanders off.
- **Minichess.** A real chess table sized down to a fast 6×6 board so a game finishes in a couple of minutes. Sit as White and either wait for a friend to take Black or hold to play a built-in AI. You aim by looking at a square, tap to pick up a piece, tap a destination to move. The win condition is simplified to capturing the king to keep things quick, both kings wear a gold crown so they read at a glance, and the full board is drawn on your HUD, lettered and oriented for your colour.
- **Tic-tac-toe.** The same look-and-tap flow against a perfect AI or a friend — you can draw it but never beat it. Sit as X, X goes first, and the grid and whose turn it is show on your HUD as the physical board fills in.

While you're at a table, a bottom-left HUD panel shows your live game state and clears itself once you walk away. (And when you climb onto the train roof, a banner reminds you that O drops you back into the cabin.)

## Capture, traps, and a hiding exploit closed

A few live-play feel and fairness fixes that land hard. Getting captured — the biggest horror beat in the game — used to register as a faint amber blink before you instantly vanished; it now hits with a sharp red flash and a strong camera shake, so the axe landing feels like the violent, decisive event it's meant to be. Tripping a fake-seeker alarm trap used to fire with only a faint hum despite being called an alarm; it now lands a short, punchy sting timed to the fear spike, so springing it actually startles.

The important fairness fix: hiding in a locker no longer betrays you. An occupied locker lit up a bright red indicator the hunting Teacher could see from across the room — your pawn was correctly hidden, but the locker itself pointed right at you, defeating the whole point. The hunting Teacher no longer sees that glow (survivors and spectators still get it as a teammate convenience), and a follow-up closes the role-reassignment hole where a survivor reassigned to Teacher mid-round would have kept seeing the across-room tell. To back that up, climbing out of a locker now drops you at a freshly-random angle and distance every time, so a Teacher can't learn a fixed set of spots to camp the door.

A couple of smaller ones round it out: the Teacher's capture-windup warning now reaches the very survivor being chased and swung at repeatedly — the player who needs it most, who'd been silently denied it for several seconds — sprint no longer rubber-bands after you toggle prone, and the low-battery flashlight message now reads "Flashlight on — battery almost gone" so you know the light *did* come on. And the emote wheel (hold X) now aims like a proper radial menu — the cursor snaps to the centre the moment it opens and you pick a wedge by pushing the mouse out toward it, instead of nudging a drifting virtual stick, so you actually land the emote you meant.

And the Teacher's legs finally tire. Sprint stamina now recovers much more slowly for the Teacher — the recovery rate dropped from comfortably *above* the drain rate to well below it — so on a small map, with scans and pings to lean on, the Teacher can no longer just hold sprint and run one student down forever. Empty the bar in a chase and you have to ease off and let it breathe before the next burst, which finally gives a fleeing student a real window to break line of sight and get away. Draining a full bar is unchanged (~5.9s of sprint); it's the refill that's been reined in (a full bar now takes ~9s instead of ~4s).

## Getting in (Windows)

Unzip it and run `BlackoutHunt.exe`. The menu reads **BUILD 0.9.0**, and the under-the-hood version strings moved with it this build: the project version, the boot-console firmware line, and the online build id are all on 0.9.0 now. So online session filtering correctly holds 0.9.0 and 0.8.x clients apart again — just make sure everyone in a session is on the same 0.9.0 build. The LAN-by-default host from 0.8.1 still applies: students can join by LAN IP if they're on the same switch, or over the tunnel from off-LAN, with a one-time Windows Firewall "Allow" the first time you host. For a hosted class over the tunnel, the playit Custom UDP mapping from the earlier notes still applies — the game detects it and walks you through it, but I can't set it up for you. Before I tag a release it goes through the automated suite and the cooked host-plus-clients playability gate (a real host plus two clients booting the package and playing through to a started round); 0.9.0 isn't tagged yet, so that's still ahead of this build, not a stamp it already carries.

## Known limits

- Still a beta — and more so than usual. This release adds a *lot* of brand-new systems at once: an entire achievements/cosmetics/prestige layer, persistent per-topic mastery, momentum movement tech, a full tutorial rebuild, a hidden HUB, a reskinned menu with a cold-boot intro, per-part recolouring, and three playable minigames. Every one of those wants a real in-engine playtest with real people, so please treat it as one and tell me what trips up :)
- 0.9.0 isn't tagged yet. The automation suite and the cooked host-plus-clients smoke run are the gate it clears *before* I tag it — so read this as the release coming together, not one that's already stamped. (A few in-engine version strings beyond the menu still need bumping to 0.9.0 first, including the online build id used for session matching.)
- The hosted-over-tunnel path still needs the Custom UDP mapping set in your playit dashboard by hand. The game detects it and walks you through it, but I can't do that part for you.
- If you run the optional self-hosted account server, the Google Sheet feedback hardening only takes effect once you redeploy the Apps Script — and that login path still ships off by default.
